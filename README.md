# ASCENT 2027 Workshop Website

Website for **ASCENT: 2nd Workshop on Advances in Systems and Computation at the Edge and HPC Networks**, organized in conjunction with ICDCN 2027 at NITK Surathkal.

## GitHub Pages

Recommended publishing settings:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

After publishing, the site will be available at:

`https://<github-username>.github.io/<repository-name>/`

## Files

- `index.html`: public website
- `assets/`: workshop and venue images
- `google_sites_build_guide.md`: optional Google Sites transfer guide
